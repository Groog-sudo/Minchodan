# [가이드] 관리자 관제 콘솔 네비게이션 실시간 지도 연동 가이드

> **작성일**: 2026-07-08
> **버전**: v1.0.0
> **수신**: 관리자 관제 콘솔 개발 담당 팀원 귀하

본 문서는 시각장애인 보행 보조 스마트 가이드독 AI 플랫폼의 실시간 길안내(네비게이션) 지도 화면을 관리자 관제 콘솔 UI 레이아웃에 깔끔하게 임베딩하고 연동하기 위한 상세 연동 지침입니다.

---

## 1. 연동 개요

네비게이션 서비스(`server/navigation`)는 별도로 8001번 포트에서 독립 기동되며, **실제 보행자가 야외에서 직접 걸으며 연동하는 실시간 GPS 및 나침반 센서 데이터를 정밀 추적하여 TTS 가이드를 실시간 출력하도록 설계**되어 있습니다. 

본 모듈은 실제 현장 보행 테스트를 완벽히 지원함과 동시에, 관리자 및 개발자가 실내에서 가상의 경로를 설정하고 동작을 모니터링할 수 있는 시뮬레이터 기능도 함께 제공합니다.

기존 관제 콘솔의 코드 수정과 복잡한 API 마운트 과정을 배제하기 위해 **비침습적 임베딩 모드(iframe)**를 지원하도록 구현되었습니다. URL 쿼리 파라미터 `?embed=true`를 붙여 호출하면, 주변 조화 UI(검색창, 설정 패널, 디버그 창 등)가 모두 제거되고 **순수 관제 지도 화면만 전체 크기**로 띄워집니다.

---

## 2. 연동 방법 (React 기반 컴포넌트 예시)

관제 콘솔의 원하는 그리드 또는 카드 레이아웃 영역 내에 아래와 같이 `<iframe>`을 작성하여 마운트해주십시오.

### 2.1. 기본 iframe 태그 사용 시
```html
<iframe 
  src="http://localhost:8001/?embed=true" 
  width="100%" 
  height="450px" 
  style="border: none; border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.4);"
></iframe>
```

### 2.2. React 컴포넌트 내 삽입 예시
```jsx
import React from 'react';

const OperatorLiveMap = () => {
  return (
    <div className="operator-map-container" style={{ width: '100%', height: '100%' }}>
      {/* 
        embed=true 파라미터를 추가하여 지도 영역만 꽉 차게 서빙받습니다.
        포트는 8001번 독립 포트를 기본으로 사용합니다.
      */}
      <iframe
        src="http://localhost:8001/?embed=true"
        title="스마트 가이드독 실시간 보행 관제 지도"
        width="100%"
        height="500px"
        style={{
          border: '1px solid rgba(255, 255, 255, 0.08)',
          borderRadius: '16px',
          boxShadow: '0 10px 30px rgba(0, 0, 0, 0.5)',
          background: '#0c0e12'
        }}
      />
    </div>
  );
};

export default OperatorLiveMap;
```

## 3. 동작 특징 및 연동 효과

* **객체 탐지 결과 실시간 융합 (조화)**: 
  * 8001번 네비게이션 서버는 백그라운드에서 기존 Minchodan 서버(8000번)가 발행하는 Redis Streams(`risk.events`)를 상시 구독 중입니다.
  * 단말기가 전송한 실시간 카메라 이미지가 8000번 서버를 거쳐 객체(장애물)를 탐지하면, 해당 탐지 이벤트가 8001번 네비게이션 지도로 자동 유입됩니다.
  * 결과적으로, 이 iframe 지도는 단순한 지도가 아니라 **사용자의 GPS 이동 궤적과 스마트폰에서 들어온 위험 객체 탐지 피드백이 실시간으로 융합(조화)**되어 렌더링되는 통합 모니터링 허브 역할을 하게 됩니다.
* **청각 관제 검증**:
  * 보행 중인 사용자에게 어떤 TTS 음성 가이드("숭례문 방향으로 우회전입니다. 전방에 전동 킥보드 주의하세요.")가 발화되고 있는지 브라우저 오디오 오버레이를 통해 실시간으로 함께 들을 수 있어, 관제 화면에서 서비스 상태의 완전한 검증이 가능합니다.

## 4. 로컬 테스트 및 서버 구동 순서

가이드라인에 따라 테스트를 수행할 때 아래 순서대로 구동해 주시기 바랍니다:

1. **기존 GPU 추론 서버 및 Redis 구동** (8000 포트)
   ```bash
   # d:\2025_langchain_ydg\TeamProject\Minchodan
   .\venv\Scripts\python.exe server/main.py
   ```
2. **네비게이션 서버 구동** (8001 포트)
   ```bash
   # d:\2025_langchain_ydg\TeamProject\Minchodan\server\navigation
   python server.py
   ```
3. **콘솔 웹페이지 실행**:
   * 마운트된 iframe 내부에서 지도가 정상적으로 불러와지는지, `localhost:8001`을 통한 웹소켓 통신 연결 상태(온라인 표시)가 올바른지 확인해주십시오.
