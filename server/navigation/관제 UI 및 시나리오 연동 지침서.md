# [가이드] 관리자 관제 콘솔 실시간 지도 임베딩 및 대화형 시나리오 가이드

> **작성일**: 2026-07-08
> **버전**: v2.1.0
> **독자**: 관리자 관제 페이지 개발 담당자, 시나리오 및 UI 기획팀

본 문서는 다른 팀원이 제작 중인 관리자 관제 콘솔 화면에 네비게이션 지도를 임베딩하는 방법과, 시각장애인 단말 앱에서 구동되는 대화형 음성 길안내 활성화 시나리오에 대해 설명합니다.

---

## 1. 대화형 길안내(네비게이션) 활성화 시나리오

앱 실행 초기에는 기존 객체 탐지 기능만 동작하여 사용 불필요 시 네비게이션이 개입하지 않으며, 사용자의 음성 명령(Wake-up)에 따라 대화식으로 기능이 켜고 꺼집니다.

* **초기 상태 (IDLE)**: 
  * YOLO 객체 탐지 모드로만 단독 작동합니다.
* **기능 시작 요청 (Wake-up)**:
  * 사용자가 **"네비게이션 켜줘"** 혹은 **"길안내 시작해줘"**라고 말하면, 시스템이 이를 감지하여 목적지 입력을 대기하는 상태(`WAITING_FOR_DESTINATION`)로 전환합니다.
  * 시스템 응답: **"네비게이션 기능을 시작합니다. 목적지를 말씀해 주세요."**
* **목적지 지정 및 주행 (`NAVIGATING`)**:
  * 사용자가 **"숭례문"** 또는 **"서울역"**과 같이 목적지를 말하면 TMAP 보행 경로를 수립하고 실제 안내를 개시합니다.
  * 시스템 응답: **"[목적지]까지 보행 경로 안내를 시작합니다."**
  * 보행 중에는 회전 안내 멘트와 돌발 위험 객체 경고가 하나로 융합되어 TTS로 송출됩니다 (예: "우회전입니다. 그리고 전방에 전동 킥보드 주의하세요.")
* **기능 종료 요청 (Shutdown)**:
  * 사용자가 **"네비게이션 꺼줘"** 혹은 **"길안내 종료"**라고 말하면 즉시 경로 데이터를 파기하고 **IDLE** 상태로 복구됩니다.
  * 시스템 응답: **"네비게이션 안내를 종료합니다."**

## 2. 관리자 관제 콘솔 지도 UI 임베딩 (iframe)

기존 관제 페이지 내에 지도를 띄우기 위해 복잡한 지도 라이브러리(Leaflet 등)나 통신 파이프라인을 중복 개발할 필요가 없습니다. 8001번 네비게이션 서버가 제공하는 **임베딩용 웹 뷰**를 이용합니다.

### 2.1. 쿼리 파라미터 옵션 (?embed=true)
* **호출 주소**: `http://localhost:8001/?embed=true`
* **동작 특징**: URL 뒤에 `embed=true`가 붙으면, 지도를 제외한 다른 컨트롤 패널(검색창, 보이스 패널, 로그 기록창 등)이 화면에서 숨겨져 **순수 지도 화면만 꽉 차게 렌더링**됩니다.

### 2.2. React 기반 관제 화면 삽입 예시
관리자 관제 웹 페이지의 실시간 관제 지도 영역 내에 아래 컴포넌트를 이식해 주십시오.

```jsx
import React from 'react';

const OperatorLiveMap = () => {
  return (
    <div style={{ width: '100%', height: '100%', minHeight: '450px' }}>
      {/* 
        8001번 독립 네비게이션 서버의 맵 뷰를 관제 콘솔 카드/레이아웃 내에 
        iframe으로 간단히 임베딩하여 연동을 완료합니다.
      */}
      <iframe
        src="http://localhost:8001/?embed=true"
        title="스마트 가이드독 실시간 보행 관제 지도"
        width="100%"
        height="100%"
        style={{
          border: '1px solid rgba(255, 255, 255, 0.08)',
          borderRadius: '16px',
          boxShadow: '0 10px 30px rgba(0, 0, 0, 0.5)',
          background: '#0c0e12',
          minHeight: '450px'
        }}
      />
    </div>
  );
};

export default OperatorLiveMap;
```

## 3. 관제 및 검증 방법
* iframe 내에 지도가 띄워지면, 단말 앱으로부터 수신되는 실제 보행자의 GPS 좌표와 이동 궤적, 그리고 YOLO 탐지 피드백이 실시간으로 동기화되어 지도에 그려집니다.
* 관리자는 사용자에게 흘러가는 융합 음성을 관제 화면상에서 함께 모니터링하여 정상 작동 여부를 직관적으로 검증할 수 있습니다.
