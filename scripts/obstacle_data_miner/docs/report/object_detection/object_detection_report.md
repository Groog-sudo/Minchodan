# Object Detection 데이터 수집 및 검증 보고서

## 1. 데이터 수집 출처 (Sources)

### 1.1 해외 데이터셋 (기존 파이프라인)
- **COCO 2017 & Open Images V7:** 일반적인 객체(사람, 자동차, 의자 등)와 `suitcase`(`carrier`로 매핑) 데이터 확보를 위해 사용.
- **ScooterDet (Zenodo):** 실제 전동 킥보드(`scooter`) 데이터를 선별적으로 수집하여 야외 보행 장애물 보강.

### 1.2 국내 데이터셋 (AI Hub 연동)
해외 데이터셋에 없는 한국형 시설물(키오스크, 볼라드, 전력제어기 등) 보강을 위해 다음 AI Hub 데이터셋을 활용했습니다.
- **dataSetSn=513 (보행 안전을 위한 도로 시설물 데이터):** Bounding Box JSON 스키마 확인. 한글/영문 혼용 텍스트(`자동차 진입 억제용 말뚝 (bollard)_정상`)에서 영문 클래스 추출.
- **dataSetSn=189 (인도보행 영상):** CVAT XML 스키마 확인. `<box label="bollard" ...>` 형태의 직접적인 영문 라벨 제공.

## 2. 데이터 변환 및 매핑 (Class Mapping)
AI Hub의 복잡한 라벨을 `config.py`에 정의된 29개 클래스로 필터링/매핑했습니다.
- **예외 처리:** 대차(구루마)와 같은 모호한 객체는 바퀴가 달린 이동형 운반구의 특성을 고려하여 `carrier` 클래스로 허용(매핑)하여 RAG/TTS 안내 시 통합 관리하도록 처리했습니다.

## 3. YOLO 박스 검증 결과 (Verification Results)
- **추출 결과:** AI Hub 샘플 데이터셋 런을 통해 **296장**의 유효 Bounding Box 데이터가 YOLO txt 포맷으로 추출됨.
- **시각화 검증:** `utils/visualize_samples.py`를 통해 원본 이미지와 추출된 YOLO Box 좌표의 일치 여부 확인 결과, 좌표의 틀어짐이나 정규화 오류 없이 정확하게 매핑됨을 증명함.
- 시각화 가시성 개선: 고해상도 원본 이미지(FHD 이상)에서도 식별 가능하도록 텍스트 배경(솔리드 박스)과 굵기를 강화하여 라벨 오인식/누락 의심을 해소.
