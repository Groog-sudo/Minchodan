# 📱 안드로이드 EAS 개발 빌드 및 실기기 무선 통합 가이드

이 문서는 시각장애인 보행 보조 플랫폼(Minchodan)의 백엔드(Docker) 환경과 최신 프론트엔드 네이티브 모듈이 탑재된 **EAS 개발 클라이언트 빌드(Development Client)**를 개인 스마트폰에 무선으로 연동하여 실시간 AI 카메라 성능을 테스트하기 위한 팀 공용 마스터 매뉴얼입니다.[cite: 9, 12]

과거 주렁주렁 선을 연결하던 레거시 USB 디버깅 방식의 한계와 파일 시스템 권한 충돌을 극복하고, 완전한 무선 하이브리드 인프라를 PC에 안착시키는 과정을 다룹니다.[cite: 9, 12]

## 🤖 1. 타 PC(학원/팀원) 기동 전 'AI 에이전트 작업 지침'
> **팀원 필독:** 다른 컴퓨터나 학원 PC에서 이 브랜치를 받아 실행할 때, 기존에 깔려있던 구형 USB 디버깅 캐시 찌꺼기나 `node_modules` 버전 꼬임으로 인해 빌드가 폭발하는 현상(`EPERM`, `Kotlin 컴파일 에러`)이 필연적으로 발생합니다.[cite: 9, 12]
>
> 프로젝트를 열자마자 **Antigravity-IDE AI 에이전트 채팅창에 아래 박스의 내용을 통째로 복사해서 입력**해 주세요. 사람의 수동 작업 없이 에이전트가 10초 만에 환경을 청정 상태로 자동 수술합니다.

```text
현재 PC 환경의 개발 환경 통합 및 무선 하이브리드 인프라 정착을 위해 다음 3단계 프로토콜을 즉각 수행해라.

1. [물리적 환경 세척]: 소스코드는 철저히 보존하되, 로컬 컴파일 충돌을 유발하는 `client/node_modules`, `client/android/.gradle`, `client/android/build`, `client/android/app/build` 캐시 폴더를 강제로 완전히 삭제해라.
2. [v4 네이티브 정합성 수술 검증]: 최신 카메라/AI 규격 동기화를 위해 아래 3대 핵심 파일의 상태를 검증하고 옛날 코드면 즉시 최신화해라.
   - `MainApplication.kt`: 레거시 호출부를 제거하고 최신 v4 규격인 `addFrameProcessorPlugin` 체계로 유지.
   - `ReflexFrameProcessorPlugin.kt`: 카메라 회전 처리 시 String 상수가 아닌 정식 `Orientation Enum` 매핑 아키텍처 적용.
   - `tfliteDetector.ts`: 온디바이스 6채널 NMS 모델 동기화를 위해 `attrsPerBox` 인자가 `6`으로 세팅되어 있는지 대조.
3. [윈도우 네이티브 의존성 재구축]: 세척이 완료되면 가상 컴퓨터(도커) 내부가 아닌, 윈도우 호스트 시스템 단에서 `client` 경로로 진입하여 `npm install`을 클린 인스톨해라.
