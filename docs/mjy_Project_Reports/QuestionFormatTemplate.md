# (비NCS)랭체인 기반 AI영상객체 플랫폼 구축 프로젝트

## 문제 : 아래의 설명을 읽고, 설명에 제시한 답안을 풀고 Notion에 정리한후 , 답안을 pdf로 업로드 하세요.

> 팀별로 수행한 최종 프로젝트의 전체 내용을 간략하게 정리하고, 프로젝트에서 본인이 담당한 기능 또는 작업의 세부 구현 과정을 구체적으로 작성하시오.

### 답안에는 다음 내용을 포함하여 문서화하시오.

1. 프로젝트 개요
   - 프로젝트명
   - 프로젝트 주제 및 개발 목적
   - 주요 사용자 또는 활용 대상
   - 프로젝트의 주요 기능

2. 프로젝트 전체 구조
   - 사용한 주요 기술 및 개발 도구
   - 프론트엔드, 백엔드, 데이터베이스, AI 모델 등의 구성
   - 데이터 또는 사용자 요청이 처리되는 전체 흐름

3. 본인의 담당 역할
   - 팀 내에서 맡은 역할
   - 본인이 직접 구현하거나 수행한 기능
   - 본인의 작업과 다른 팀원의 작업이 연결되는 부분

4. 세부 구현 내용
   - 기능 구현을 위해 사용한 기술, 라이브러리 또는 프레임워크
   - 입력 데이터 또는 사용자 입력
   - 주요 처리 과정과 코드의 동작 원리
   - 데이터베이스, API, AI 모델 또는 화면과의 연동 과정
   - 최종 출력 결과 및 구현 화면

5. 문제 해결 과정
   - 구현 중 발생한 오류 또는 기술적 문제
   - 문제의 원인
   - 해결을 위해 시도한 방법
   - 최종 해결 결과

6. 프로젝트 평가 및 개선 방향
   - 프로젝트의 성과
   - 현재 구현의 부족한 점
   - 향후 추가하거나 개선하고 싶은 기능

### 작성 유의사항

- 팀 전체의 작업과 본인이 직접 수행한 작업을 명확하게 구분하여 작성한다.
- 단순히 기능명이나 결과만 나열하지 않고, 입력 → 처리 → 출력의 순서로 설명한다.
- 본인이 작성한 코드, 구현 화면, 데이터 처리 결과, 모델 평가 결과 또는 API 요청·응답 예시 등을 근거 자료로 제시한다.
- 구현 과정은 다른 사람이 문서를 읽고 기능의 동작 방식을 이해할 수 있도록 구체적으로 작성한다.
- 인터넷 자료나 팀원의 내용을 그대로 복사하지 않고, 본인이 실제로 수행하고 이해한 내용을 중심으로 작성한다.
