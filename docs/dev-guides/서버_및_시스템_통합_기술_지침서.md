> **작성일**: 2026-07-08
> **버전**: v2.1.0

* **네비게이션 서버 기동 포트**: **8001** (기존 YOLO 추론 서버 포트 8000과 독립 실행)

## 2. 의존성 및 환경 변수 설정

### 2.1. TMAP API Key 설정
TMAP 보행자 경로 API 연동을 위해 발급받은 API Key를 프로젝트 루트 `.env` 파일(`d:\2025_langchain_ydg\TeamProject\Minchodan\.env`)에 추가합니다.
```env
# --- TMAP Navigation API Key ---
TMAP_APP_KEY=실제_발급받은_티맵_앱_키
```

### 2.2. 패키지 의존성
로컬 개발 환경의 가상환경(`venv`)이 활성화된 상태에서 아래 패키지를 추가 설치해야 할 수 있습니다.
* **pyttsx3**: 로컬 오디오 음성 출력이 필요한 검증 단계에서 사용합니다.
```bash
.\venv\Scripts\pip install pyttsx3
```

## 3. 핵심 백엔드 소스코드 수정 사양

백엔드 시스템 연동을 위해 수정한 5대 핵심 파일의 구체적인 소스코드 결합 사양입니다.

### 3.1. [stt_to_llm_bridge.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/stt/stt_to_llm_bridge.py)
* **목적**: STT 텍스트 수신 시 명령어 분류 및 네비게이션 세션 상태 제어
* **구현**:
  - 유입된 텍스트 중 키워드 분류를 거쳐 네비게이션 활성화(`WAITING_FOR_DESTINATION`), 목적지 설정(TMAP API 호출 및 `NavigationManager.update_route` 반영), 또는 비활성화(`IDLE` 및 경로 초기화) 처리를 수행합니다.

### 3.2. [ws_router.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/api/ws_router.py)
* **목적**: 단말기로부터 전달받은 GPS 데이터의 실시간 수집 및 전파
* **구현**:
  - 웹소켓 `/ws/detect` 엔드포인트의 `detection` 페이로드 또는 `realtime_gps` 메시지 타입에서 `gps` 정보(`lat`, `lon`, `heading`)를 가로채 `NavigationManager.update_gps`에 바인딩합니다.

### 3.3. [consumer.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/detection/consumer.py)
* **목적**: 객체 탐지 최종 가이드 송출 전 네비게이션 멘트 주입
* **구현**:
  - `_send_cognitive_guide`에서 오케스트레이터를 호출하기 직전, `NavigationManager.get_combined_guidance`를 조회해 현재 시점의 도보 안내 멘트를 획득하고 이를 `orch_input` 컨텍스트에 포함시킵니다.

### 3.4. [state.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/orchestration/state.py)
* **목적**: LangGraph 노드 간 네비게이션 데이터 전송 필드 정의
* **구현**:
  - `OrchState` TypedDict 규격 내에 `navigation_guidance` 필드를 추가하여 L2 노드까지 안전하게 전달되도록 보장합니다.

### 3.5. [l2_generator.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/orchestration/nodes/l2_generator.py)
* **목적**: LLM 융합 안내문 생성
* **구현**:
  - Ollama(gemma4-e4b) 호출 프롬프트 내에 `[길안내 멘트]`를 매핑하여, 장애물 탐지 상황과 네비게이션 이동 경로 가이드가 논리적으로 조합된 20자 이내의 한국어 1문장을 출력하도록 유도합니다.

## 4. 백엔드 시스템 기동 및 검증

1. **기존 GPU 서버 실행**:
   ```bash
   .\venv\Scripts\python.exe server/main.py
   ```
2. **독립 네비게이션 서버 실행**:
   ```bash
   cd server/navigation
   ..\..\venv\Scripts\python.exe server.py
   ```
   * 백그라운드 Redis Stream `risk.events` 구독 로그 및 웹소켓 바인딩 상태가 정상인지 점검합니다.
