# Minchodan 네비게이션 백엔드 시스템 통합(Integration) 기술 지침서

> **작성일**: 2026-07-08
> **버전**: v2.2.0
> **독자**: 백엔드 개발자 및 시스템 엔지니어

본 문서는 실시간 길안내(네비게이션) 서비스를 메인 백엔드 서버에 마운트하고, ngrok 터널을 경유하여 외부 실제 단말(iOS) 및 관제 화면과 통신을 비침습적으로 연동하기 위한 백엔드 기술 지침서입니다.

---

## 1. 모듈 파일 배치 및 단일 포트(8000) 통합 구동

네비게이션 모듈은 별도의 8001번 독립 포트를 사용하지 않고, 기존 Minchodan 메인 서버(8000 포트)에 **서브앱(Sub-app)**으로 마운트되어 통합 구동됩니다.
* **배치 경로**: `d:\2025_langchain_ydg\TeamProject\Minchodan\server\navigation\`
* **FastAPI 통합 마운트 구현**:
  * 메인 서버 entrypoint(예: `server/main.py`) 내부에서 아래와 같이 네비게이션 서브앱을 마운트하여 단일 포트 8000번 하위의 `/navigation` 경로로 통합 제공합니다.
  ```python
  from fastapi import FastAPI
  from server.navigation.server import app as navigation_app

  app = FastAPI()
  # 8000번 포트 하위에 네비게이션 서브앱 마운트
  app.mount("/navigation", navigation_app)
  ```

---

## 2. ngrok 터널링을 이용한 통신 채널 개방

실기기(iOS 앱) 테스트 환경 및 야외 현장 도보 실측을 지원하기 위해, ngrok 터널링을 통해 로컬 8000번 서버를 외부 인터넷 도메인으로 매핑합니다.
* **ngrok 기동 명령어**:
  ```bash
  ngrok http 8000
  ```
* **도출 도메인 적용 예시**:
  * **API 및 웹페이지 주소**: `https://xxxx.ngrok-free.app/navigation/`
  * **웹소켓 통신 주소**: `wss://xxxx.ngrok-free.app/navigation/ws`

## 3. 핵심 백엔드 소스코드 수정 및 연동 규격

### 3.1. [stt_to_llm_bridge.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/stt/stt_to_llm_bridge.py)
* **목적**: 마이크 음성 인식(STT) 명령어 분류 및 네비게이션 상태(IDLE ➔ WAITING ➔ NAVIGATING) 제어.
* **구현**:
  * `"네비게이션 켜줘"` 등의 명령 감지 시 대기 상태 전환 및 목적지 유도 응답 발화. 목적지 명사 셋업 시 TMAP 경로 조회를 거쳐 안내 중 상태로 진입.

### 3.2. [ws_router.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/api/ws_router.py)
* **목적**: 단말기로부터 전달받은 GPS 데이터의 실시간 수집 및 전파.
* **구현**:
  * ngrok 주소를 거쳐 수신된 아이폰의 실시간 웹소켓 프레임(`detection` 페이로드) 내 `gps` 필드(`lat`, `lon`, `heading`) 데이터를 `NavigationManager.update_gps`로 자동 연계.

### 3.3. [consumer.py](file:///d:/2025_langchain_ydg/TeamProject/Minchodan/server/detection/consumer.py)
* **목적**: 객체 탐지 최종 가이드 송출 전 네비게이션 멘트 주입.
* **구현**:
  * `_send_cognitive_guide`에서 오케스트레이터 호출 직전 `NavigationManager.get_combined_guidance`를 조회해 현재 위치의 보행자 방향 전환 가이드를 획득하고, 이를 기존 YOLO 인지 가이드 문장에 주입.

## 4. 백엔드 시스템 기동 및 검증 순서

1. **기존 도커 및 로컬 서버 실행** (8000 포트 단일 구동):
   ```bash
   .\venv\Scripts\python.exe server/main.py
   ```
2. **ngrok 터널링 시작**:
   ```bash
   ngrok http 8000
   ```
3. 아이폰의 웹소켓 연결이 ngrok 터널(`wss://xxxx.ngrok-free.app/ws/detect`)을 통해 안정적으로 도커/로컬 백엔드로 인입되는지 로그를 통해 확인합니다.
