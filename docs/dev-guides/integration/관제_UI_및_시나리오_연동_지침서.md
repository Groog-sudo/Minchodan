# 관제 UI 및 시나리오 연동 지침서

> **작성일**: 2026-07-08
> **버전**: v2.3.1 (2026-07-19 Tailscale Serve HTTPS MagicDNS/443 관제 경로 반영)
> **독자**: 관리자 관제 페이지 개발 담당자, 시나리오 및 UI 기획팀

본 문서는 다른 팀원이 제작 중인 관리자 관제 콘솔 화면에 네비게이션 지도를 임베딩하는 방법과, 실제 스마트폰(iOS) 환경에서 구동되는 대화형 음성 길안내 활성화 시나리오에 대해 설명합니다.

## 1. 대화형 길안내(네비게이션) 활성화 시나리오

앱 실행 초기에는 기존 객체 탐지 기능만 동작하여 사용 불필요 시 네비게이션이 개입하지 않으며, 사용자의 음성 명령(Wake-up)에 따라 대화식으로 기능이 켜고 꺼집니다.

* **초기 상태 (IDLE)**:
  * YOLO 객체 탐지 모드로만 단독 작동합니다.
* **기능 시작 요청 (Wake-up)**:
  * 사용자가 아이폰 마이크에 대고 **"네비게이션 켜줘"** 혹은 **"길안내 시작해줘"**라고 말하면, 시스템이 이를 감지하여 목적지 입력을 대기하는 상태(`WAITING_FOR_DESTINATION`)로 전환합니다.
  * 시스템 응답: **"네비게이션 기능을 시작합니다. 목적지를 말씀해 주세요."**
  * **2026-07-10 확장**: 위 단일 트리거 외에 **"길댕아"** 2단계 웨이크워드가 추가되었습니다(편집거리 1 이하 퍼지 매칭으로 STT 오인식 변형 흡수). "길댕아" 호출 후 "길찾아줘"(길안내) 또는 "물어볼게"(자유 질의응답)로 분기하며, "길댕아 길찾아줘" 결합 발화도 1턴에 처리됩니다. 상세 명령 어휘는 [`docs/design/api_specification.md`](../../design/api_specification.md) §6.3 참조.
* **목적지 지정 및 주행 (`NAVIGATING`)**:
  * 사용자가 **"숭례문"** 또는 **"서울역"**과 같이 목적지를 말하면 TMAP 보행 경로를 수립하고 실제 안내를 개시합니다.
  * 시스템 응답: **"[목적지]까지 보행 경로 안내를 시작합니다."** (**2026-07-11 확장**: 경로의 첫 유의미 웨이포인트 지시가 이어집니다 - 예: "... 먼저, 세종대로를 따라 직진하세요.")
  * 보행 중에는 회전 안내 멘트와 인지 경로(mid/low)의 장애물 안내가 융합되어 TTS로 송출됩니다 (예: "우회전입니다. 그리고 전방에 전동 킥보드 주의하세요."). **2026-07-11 보강**: 회전 안내는 카메라 탐지와 무관하게 GPS 수신 시점에도 독립 발화됩니다(빈 장면 무음 결함 수정).
  * **비협상 원칙**: 고위험(high) 즉시 경보는 네비게이션 멘트와 융합되지 않고 반사 경로의 사전합성 클립·햅틱으로 별도 선점 재생됩니다.
* **기능 종료 요청 (Shutdown)**:
  * 사용자가 **"네비게이션 꺼줘"** 혹은 **"길안내 종료"**라고 말하면 즉시 경로 데이터를 파기하고 **IDLE** 상태로 복구됩니다.
  * 시스템 응답: **"네비게이션 안내를 종료합니다."**

## 2. 관리자 관제 콘솔 지도 UI 임베딩 (로컬 8000 및 Tailscale Serve 443 기준)

8001번 독립 포트를 띄우지 않고, 로컬 8000번 메인 FastAPI의 `/navigation` 경로를 Tailscale Serve 443 TLS 종단으로 제공합니다.

### 2.1. 쿼리 파라미터 옵션 및 임베딩 주소
* **로컬 접속 주소**: `http://localhost:8000/navigation/?embed=true`
* **Tailscale 원격 접속 주소**: `https://[SERVER_MAGICDNS_NAME]/navigation/?embed=true` (현장 도보 실측 시 외부 관제용)
* **동작 특징**: URL 뒤에 `embed=true`가 붙으면, 지도를 제외한 다른 컨트롤 패널(검색창, 보이스 패널, 로그 기록창 등)이 화면에서 숨겨져 **순수 지도 화면만 꽉 차게 렌더링**됩니다.

### 2.2. React 기반 관제 화면 삽입 예시
관리자 관제 웹 페이지의 실시간 관제 지도 영역 내에 아래 컴포넌트를 이식해 주십시오.

```jsx
import React from 'react';

const OperatorLiveMap = () => {
  return (
    <div style={{ width: '100%', height: '100%', minHeight: '450px' }}>
      {/*
        메인 서버의 Tailscale Serve 주소 하위 서브앱 경로(/navigation)를
        관제 콘솔 내에 iframe으로 임베딩하여 연동을 완료합니다.
      */}
      <iframe
        src="https://[SERVER_MAGICDNS_NAME]/navigation/?embed=true"
        title="스마트 가이드독 실시간 보행 관제 지도"
        width="100%"
        height="100%"
        style={{
          border: '1px solid rgba(255, 255, 255, 0.08)',
          borderRadius: '16px',
          boxShadow: '0 10px 30px rgba(0, 0, 0, 0.5)',
          background: '#0c0e12',
          minHeight: '450px'
        }}
      />
    </div>
  );
};

export default OperatorLiveMap;
```

## 3. 관제 및 검증 방법
* Tailscale 사설망으로 인입되는 아이폰 사용자의 실시간 GPS 좌표, 이동 궤적, 그리고 YOLO 탐지 피드백이 실시간으로 관제 화면(지도) 상에 동기화되어 그려집니다.
* 관리자는 사용자에게 흘러가는 융합 음성을 관제 화면상에서 함께 모니터링하여 정상 작동 여부를 원격으로 검증할 수 있습니다.

> **2026-07-11 구현 현황**: 콘솔의 `OperatorLiveMap.tsx`는 구버전 8001 독립 포트 주소로
> 하드코딩된 채 `App.tsx`에서 주석 처리(비활성)되어 있었으며, kb 브랜치에서 §2의 8000
> 서브앱 경로(`VITE_NAV_MAP_URL` 환경변수, 기본 `http://localhost:8000/navigation/?embed=true`)로
> 수정하고 재활성화했습니다. 별개로 **단말(iOS 앱)에도 하단 T맵 지도 패널**
> (`client/src/components/NavMapPanel.tsx`, `nav_route` 메시지 기반)이 운영자/데모용으로
> 존재합니다 - 관제 콘솔 지도(서브앱 iframe)와 단말 지도 패널은 서로 다른 화면입니다.
